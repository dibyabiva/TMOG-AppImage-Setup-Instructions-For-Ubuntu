# TMOG AppImage Setup Instructions For Ubuntu

## TMOG Installation
- Install dependencies
  ```
  sudo apt install libfuse2 libwebkit2gtk-4.1-0
  ```
- Download Linux AppImage from https://tmog.org/
- Install TMOG for easy access
  ```
  ./install.sh <path/to/downloaded/AppImage>
  ```

You should now be able to search for TMOG or Task Manager in your applications menu.

You can delete the downloaded files. It has been set up inside ~/tmog
